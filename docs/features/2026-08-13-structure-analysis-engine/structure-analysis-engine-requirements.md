# 요구사항: 구조 분석 엔진

> **모드**: Socratic (자유 형식). 다음 단계의 `tech-design` 가 본 문서를 자유 형식 산문으로 읽습니다 (PRD 6 섹션 ID 강제 X).

---

## 1. 배경 — 이 층이 답하는 질문

DartWeave 5단 서사에서 이 층은 ④와 ⑤다.

```
① 벡터로는 관계를 못 본다
② 그래프로 관계를 만들었다
③ 그 관계가 맞는지 검증했다          ← 층 0 (설계 완료)
④ 검증된 그래프에서 구조를 읽었다      ← 본 문서
⑤ 그 구조는 어느 공시에도 없던 답이다   ← 본 문서
```

**이 층이 답하는 질문의 형태**는 아래층과 근본적으로 다르다.

| | 층 0 | 층 1 |
|---|---|---|
| 질문 | *"삼성전자의 공급사는?"* | *"이 산업에서 소수에 의존하는 구간이 어디인가?"* |
| 답이 있는 곳 | 어느 공시 문단 | **어느 공시에도 없음 — 분포에 있음** |
| 근거의 형태 | 원문 인용 | **계산 내역** |

**근거를 문장이 아니라 숫자로 낸다는 것이 이 층의 정체성이다.** 원문 인용은 *"해석이 다르다"* 가 가능하지만 계산 내역은 그게 안 된다. 반박하려면 계산을 반박해야 한다.

## 2. 범위

| 검증 ③ 귀무모형 대조 | |

**완료 판정 한 줄**: *"CLI로 렌즈와 질문을 주면, 근거 블록에 들어갈 수치 묶음과 그것을 해석한 한 문단이 나온다. 그리고 그 결론이 파라미터에 안 휘둘린다는 증거가 함께 나온다."*

## 3. 층 0에서 받는 것 (이미 보장됨)

| 필요 | 층 0 AC |
|---|---|
| 가중치 인자 (출처 · 교차확인 · `mention_count` · `share_pct`) | AC-3 · AC-8 |
| 방향 보존 그래프 | AC-9 |

**층 0에 추가로 요구하는 것은 없다.** 이 문서를 쓰는 목적 중 하나가 그 확인이었고, 확인됐다.

## 4. 핵심 결정

### 결정 1 — 렌즈는 **이진 선택**이다. 중간값 튜닝을 하지 않는다

렌즈는 *"무엇을 보고 싶은가"* 의 선언이다. 관계 타입을 **살리거나 죽이거나**만 한다.

```
공급망 렌즈    = { SUPPLIES_TO, PRODUCES }
지배구조 렌즈  = { MAJOR_SHAREHOLDER_OF, INVESTS_IN, HOLDS_5PCT }
인적망 렌즈    = { EXECUTIVE_OF }
```

**근거**: *"공급망 렌즈는 공급·생산 관계만 본다"* 가 *"지분을 0.1로 뒀다"* 보다 방어하기 쉽다. `왜 0.1인데요?` 에 답할 방법이 없다. **임의성을 이진 선택 하나로 격리한다.**

### 결정 2 — 최종 가중치는 3겹. 임의로 정하는 건 겹1뿐이다

```
최종 가중치 = 렌즈(0 또는 1) × 근거강도 × 정량속성
              └ 겹1 (본 문서)  └ 겹2 (층 0 산출)  └ 겹3 (층 0 산출)
```

> ⚠️ **단, 겹2의 계수도 완전히 객관적이진 않다.** 교차확인 가산·반복언급 가산의 **방향**(교차확인이 더 무겁다)은 자명하지만 **크기**는 임의값이다. 따라서 **겹2 계수도 민감도 스윕 대상에 포함한다** (결정 8).

### 결정 3 — 투영은 두 벌. 단일 진실은 층 0의 저장이다

```
Neo4j 저장 (방향 O)
   ├─ NATURAL    → 층위 · 중심성
   └─ UNDIRECTED → Leiden 군집
```

선택이 아니라 제약의 귀결이다. Leiden은 `UNDIRECTED` 를 요구하고 층위는 방향이 필요하다.

### 결정 4 — 군집과 층위를 **분리**한다. 그리고 군집에 의미 라벨을 붙이지 않는다

| | 답하는 질문 | 산출 |
|---|---|---|
| **군집** | *누구와 뭉치나* | Leiden 커뮤니티 번호 |
| **층위** | *공급망 어디쯤인가* | 입·출차수 비 · 공급 깊이 |

**커뮤니티 탐지는 "소재/부품/장비" 같은 밸류체인 단계를 답하지 않는다.** 엣지 밀도만 보므로 계열사끼리 뭉칠 확률이 높다. 밸류체인 층위는 방향 그래프의 위상에서 나온다.

> ⚠️ **군집에 사람이 의미 라벨을 붙이는 코드를 만들지 않는다.** *"군집 3 = 소재"* 라고 이름 붙이는 순간, 결론이 데이터가 아니라 라벨에서 나온다. 서술은 **군집 번호 + 층위 수치**로만 한다.
>
> ❌ *"소재 군집은 의존도가 26.1이다"*
> ✅ *"군집 3은 노드 11개, 외부 엣지 287개, 의존도 26.1, 평균 공급깊이 0.4(상류)다"*

### 결정 5 — Louvain을 쓰지 않는다. Leiden만 쓴다

Louvain은 **연결조차 안 된 군집을 만들어낼 수 있다** — 군집의 최대 25%가 제대로 연결되지 않고 최대 16%는 아예 분리된다는 실험 결과가 있다. Leiden은 **군집의 연결성을 증명으로 보장**하며 더 빠르다 (Traag, Waltman & van Eck, *Scientific Reports* 9:5233, 2019).

**"우리가 찾은 군집"이 사실 두 개의 분리된 덩어리라면 분석 전체가 무너진다.** 이건 취향이 아니라 보장 때문의 선택이다.

### 결정 6 — 모듈러리티에 **절대 기준을 쓰지 않는다.** 반드시 귀무모형과 대조한다

*"0.3 이상이면 좋다"* 같은 수치가 널리 인용되지만 **문헌 기준이 아니다.** 네트워크 크기·밀도에 따라 달라진다.

판정은 **같은 그래프의 무작위 버전과의 대조**로만 한다. 그리고 그 무작위 버전은:

> ⚠️ **차수 보존 셔플이어야 한다.** 완전 무작위 셔플은 허브 구조까지 파괴해서 무작위 모듈러리티를 부당하게 낮게 만든다 — *"구조가 없어서"* 가 아니라 *"허브를 없애서"* 나온 숫자가 된다.
>
> *"허브 구조가 똑같은데도 군집이 안 생긴다"* — 이게 정직한 증명이다.

### 결정 7 — CPM을 병행한다. GDS만으로는 작은 군집을 못 본다

모듈러리티 최적화는 **네트워크 전체 크기에 의존하는 규모보다 작은 모듈을 원리적으로 식별하지 못한다.** 내부 밀도가 최대인 클리크여도 단일 엣지 하나면 인접 군집에 병합된다 (Fortunato & Barthélemy, *PNAS* 104(1):36–41, 2007).

그리고 **GDS Leiden은 모듈러리티 전용이다** (2.13 기준 CPM 목적함수 옵션 없음). 따라서:

```
GDS Leiden (모듈러리티)  →  주 결과
igraph CPM              →  대조 결과 (작은 군집 누락 확인)
```

**두 결과의 군집 수·구성 차이를 비교표로 낸다.** 차이가 크면 해상도 한계가 실제로 작동했다는 뜻이고, 그 사실 자체를 보고한다.

### 결정 8 — 민감도 스윕. **전 구간에서 유지되는 결론만 채택한다**

해상도를 바꾸면 군집 개수가 달라진다. **결론이 파라미터 선택에 좌우되면 못 쓴다.**

스윕 대상은 둘이다:
- **해상도** (Leiden `gamma` / CPM resolution)
- **겹2 계수** (교차확인 가산 · 반복언급 가산) ← 결정 2의 임의성 보완

특정 구간에서만 성립하는 결론은 **보고하지 않는다.** 파라미터를 잘 골라서 나온 우연이기 때문이다.

### 결정 9 — LLM은 **숫자를 만들지 않는다.** 계산 결과를 문장으로 옮기기만 한다

```
[계산]  엔진이 지표표를 만든다  →  숫자는 여기서만 나온다
[해석]  LLM은 그 표만 보고 문장을 쓴다  →  지어낼 여지가 없다
```

프롬프트 제약: **입력 수치에 없는 고유명사·숫자를 출력에 넣지 않는다.** 이건 검증 가능해야 한다 (AC-9).

**근거**: 환각을 사후에 잡는 게 아니라 **구조적으로 발생 못 하게** 한다. 조건이 없으면 모델에게 묻지 않는 것과 같은 패턴이다.

### 결정 10 — **"결론 없음"도 정식 산출물이다**

이 층의 가장 큰 위험은 기술적 실패가 아니라 **데이터를 결론에 맞추는 것**이다. 하이라이트 문장이 나와야 한다는 압력이 있으면 파라미터를 만질 유혹이 생긴다.

그래서 다음 세 가지를 **정식 출력 상태**로 둔다:

| 상태 | 언제 | 출력 |
|---|---|---|
| `결론 채택` | 지표에 뚜렷한 편차 + 전 구간 유지 | 해석 문장 + 근거 블록 |
| **`결론 없음`** | 지표가 평평함 | *"이 산업은 특정 군집 집중이 관측되지 않는다"* — **이것도 발견이다** |
| **`파라미터 의존적`** | 스윕에서 결론이 뒤집힘 | *"이 결론은 파라미터 선택에 좌우되므로 보고하지 않는다"* + 뒤집힌 구간 |

**`결론 없음`이 실패가 아니라는 것을 코드 레벨에서 보장한다.** 세 상태가 동등한 반환값이어야 한다.

### 결정 11 — 층 0 품질이 임계 미만이면 **분석을 실행하지 않는다**

해소율이 낮으면 재현율은 추출 품질이 아니라 매핑 실패를 측정한 값이다. 그런 그래프 위에서 계산한 의존도는 의미가 없다.

**게이트 순서: 해소율 → 재현율 → 분석 실행.** 미달이면 실행을 거부하고 사유와 수치를 반환한다. *"일단 돌려보고 나중에 판단"* 을 허용하지 않는다.

## 5. 근거 블록의 구성 (이 층의 최종 산출물)

층 2가 렌더할 데이터 구조. **이 형태가 곧 이 층의 계약이다.**

```
답변 문장 (LLM 해석 — 아래 수치만으로 작성됨)

┌ 근거 ────────────────────────────────────────────
│ 렌즈        <렌즈명> (<include 관계타입 목록>)
│ 알고리즘    Leiden(모듈러리티) · <군집 수>개 군집
│
│ 군집   노드   내부엣지   외부엣지   의존도   평균공급깊이
│ ...    ...    ...        ...        ...      ...
│
│ ─ 검증 ────────────────────────────────────────
│ ① 엣지     재현율 <근사치> · 정밀도 <표본 n건> · 해소율 <x>
│ ② 규칙     규칙위반 <n>건 · 고립 <n> · 중복 <x>
│ ③ 구조     모듈러리티 <실제> vs 차수보존무작위 <평균±표준편차>
│            CPM 대조 — 군집 <n>개 (모듈러리티 대비 차이 <설명>)
│ ④ 안정성   해상도 <구간>에서 결론 <유지/뒤집힘>
│            겹2 계수 <구간>에서 결론 <유지/뒤집힘>
│
│ 범위        <대상 산업군> · 기업 <n>사 · 공시 <n>건 · <사업연도>
│ 상태        결론 채택 | 결론 없음 | 파라미터 의존적
└──────────────────────────────────────────────────
```

> ⚠️ **`범위` 줄이 빠지면 안 된다.** 데이터가 좁은 건 결함이 아니지만, **범위를 안 밝히고 일반화하는 건 결함이다.**

## 6. 수용 기준

- **AC-1** 렌즈 프리셋이 데이터(설정)로 정의되고, 각 렌즈는 **include 관계타입 목록만으로** 표현된다. **중간 가중치 상수가 코드에 존재하지 않는다.**
- **AC-2** 층 0의 `evidence_weight` 가 가중치 속성으로 주입되어 군집 탐지가 **가중 실행**된다. 미주입(무가중) 실행과 결과가 다름을 확인할 수 있다.
- **AC-3** 투영 두 벌(NATURAL / UNDIRECTED)이 생성되고, 각각 다른 알고리즘 군에 사용된다.
- **AC-4** 군집 결과와 층위 결과가 **별도 산출물**로 나온다. **군집에 의미 라벨을 부여하는 코드 경로가 존재하지 않는다.**
- **AC-5** 모듈러리티가 **차수 보존** 귀무모형 반복과 대조되어 `(실제, 무작위 평균, 표준편차)` 로 출력된다. **반복 횟수가 설정으로 정의되고 출력에 명시된다.** 완전 무작위 셔플을 쓰지 않는다.
- **AC-6** GDS 모듈러리티 결과와 igraph CPM 결과가 **모두** 산출되고, 군집 수·구성 차이가 비교표로 나온다.
- **AC-7** 해상도 민감도 스윕이 **최소 4개 값**으로 실행되고, 각 값에서 핵심 지표가 출력된다.
- **AC-8** **겹2 계수**(교차확인 가산 · 반복언급 가산)에 대해서도 민감도 스윕이 실행된다.
- **AC-9** LLM 해석 출력에 **입력 수치에 없는 고유명사·숫자가 포함되지 않는다.** 이 검사가 자동으로 수행된다.
- **AC-10** `결론 채택` · `결론 없음` · `파라미터 의존적` 세 상태가 **동등한 반환값**으로 존재한다. `결론 없음` 이 예외·에러로 처리되지 않는다.
- **AC-11** 근거 블록 데이터(§5)가 하나의 구조체로 직렬화된다 — 층 2의 렌더 입력이자 이 층의 계약.
- **AC-12** 층 0 품질 게이트가 **해소율 → 재현율 순으로** 검사되고, 미달 시 분석을 실행하지 않고 사유와 수치를 반환한다. **임계값이 설정으로 정의되고 출력에 명시된다** — 코드에 매직넘버로 박히지 않는다.
- **AC-13** 모든 출력에 **분석 범위**(대상 산업군 · 기업 수 · 공시 건수 · 사업연도)가 포함된다.
